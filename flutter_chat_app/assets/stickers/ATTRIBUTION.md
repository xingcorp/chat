# Sticker Sources and Attribution

This project uses online sticker image URLs from open/free sources.

## Primary source for featured packs

- Source: [uwx/fluentui-twemoji-3d](https://github.com/uwx/fluentui-twemoji-3d)
- CDN endpoint pattern used in `sticker_packs.json`:
  - `https://uwx.github.io/fluentui-twemoji-3d/export/3D_png/72x72/<emoji_hex>.png`

## Upstream licenses

- [microsoft/fluentui-emoji](https://github.com/microsoft/fluentui-emoji): MIT

- [uwx/fluentui-twemoji-3d](https://github.com/uwx/fluentui-twemoji-3d): MIT

## Existing packs

- Some non-featured packs use Twemoji CDN URLs.
- Twemoji license: CC-BY 4.0.

Note: Official sticker assets from Zalo/LINE/Messenger are typically proprietary and should not be redistributed without explicit rights.
