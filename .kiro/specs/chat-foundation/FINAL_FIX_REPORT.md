## 💡 KEY LEARNINGS

1. **Injectable auto-generation is essential**
   - Manual registration is error-prone
   - Always use @injectable annotations
   - Run build_runner after changes

2. **Backward compatibility matters**
   - Added getters instead of renaming properties
   - Preserved existing API contracts
   - Avoided breaking changes

3. **BLoC patterns vary**
   - Not all BLoCs need BaseBloc
   - Freezed vs Equatable for states
   - Direct Bloc<Event, State> is simpler

4. **UI-BLoC coupling**
   - UI must match BLoC event signatures
   - Event parameters must be exact
   - Type safety is critical

5. **Systematic approach works**
   - Fix DI first (foundation)
   - Then entities (data layer)
   - Then BLoCs (business logic)
   - Finally UI (presentation)
