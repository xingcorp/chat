## 🚀 Quick Start

### 1. Test It Out
Edit any Flutter file:
```bash
# Open any file in flutter_chat_app/lib/
# Make a change
# Save
# Watch hooks provide feedback in chat
```

### 2. Run Pre-Commit Check
```
1. Open Command Palette (Cmd/Ctrl + Shift + P)
2. Type "Kiro: Run Hook"
3. Select "Pre-Commit Validation"
4. Review comprehensive checklist
```

### 3. Review Hook Feedback
When hooks provide feedback:
- 🔴 CRITICAL - Fix immediately
- 🟡 HIGH - Fix before commit
- 🟢 MEDIUM - Review and consider
- 🔵 INFO - Good to know

## 🔧 Customization

### Disable a Hook
```json
{
  "enabled": false
}
```

### Adjust Patterns
```json
{
  "when": {
    "patterns": [
      "your/custom/path/**/*.dart"
    ]
  }
}
```

### Modify Checks
Edit the `then.prompt` field in hook file.
